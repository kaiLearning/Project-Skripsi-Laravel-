
# Sistem Prediksi Penjualan Toko Sembako Kaka

## Deskripsi
Project ini merupakan aplikasi berbasis web yang
dikembangkan sebagai tugas akhir perkuliahan S1
Teknik Informatika. Aplikasi digunakan untuk
memprediksi kategori penjualan produk di Toko
Sembako Kaka.

## Metode
- **Naive Bayes:** digunakan untuk memprediksi kategori
  penjualan produk berdasarkan data penjualan.
- **Confusion Matrix:** digunakan untuk mengevaluasi
  hasil klasifikasi dan mengukur kinerja model,
  termasuk nilai akurasi.

## Kategori Prediksi
- Tinggi
- Rendah
- Sangat Rendah
